    How to survive

    • Move WASD · Look mouse · Run Shift · Crouch C/Ctrl · Flashlight F / left-click · Use E / right-click · Drink Q
    • Your flashlight never dies. That doesn't mean you should always use it.
    • Find the exit on each level. Signs glow; listen for the hum.
    • Running is loud. Crouching is quiet. Darkness hides you — and drains your sanity.
    • Almond water restores sanity and stamina. Low sanity means you'll see things that aren't there.
    • Anything can be on any level. Learn their rules: some only move when unwatched, some only in the dark, some come to the light.
    • If something is peeking around a corner, it hasn't decided yet.
